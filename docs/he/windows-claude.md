# התקנת Clicky ב-Windows (עם מנוי Claude)

[→ חזרה להתחלה](../../README.md) · [English](../en/windows-claude.md) · [יש לי מק](mac-claude.md)

> **העמוד הזה ל-Windows 10 או 11.** יש לכם מק? [עוברים לעמוד של המק](mac-claude.md).
> ב-Windows, Clicky עובד עם מנוי **Claude**. (האפשרות של ChatGPT / Codex למק בלבד כרגע.)

**הזמן שלך:** בערך 10 דקות, ועוד כמה דקות של הורדות אוטומטיות בפעם הראשונה שפותחים את Clicky.
**עלות:** שום דבר מעבר למנוי Claude שאתם כבר משלמים עליו. בלי מפתח API.

---

## לפני שמתחילים

| מה צריך | פרטים |
|---|---|
| **מחשב Windows** | ‏Windows 10 או 11. |
| **מנוי Claude** | **Pro או Max** (גם Ultra, Team ו-Enterprise עובדים). התוכנית החינמית של claude.ai **לא** כוללת את Claude Code, ו-Clicky צריך אותו. |
| **כ-5GB פנויים בדיסק** | Clicky מוריד את מודלי הדיבור והקול בפעם הראשונה. |
| **אינטרנט** | להתקנה ולהפעלה הראשונה. |
| **מיקרופון** | המובנה מספיק. |

## איך זה עובד (30 שניות)

Clicky עונה לכם בעזרת Claude. הוא מדבר עם Claude דרך **Claude Code**, האפליקציה הרשמית של Anthropic, שמחוברת למנוי שלכם. לכן יש ארבעה צעדים קטנים:

1. **להתקין את Clicky.**
2. **להתקין את Claude Code ולהתחבר** (פעם אחת).
3. **לוודא ש-Clicky משתמש במנוי Claude שלכם.**
4. **לנסות.**

אחרי צעד 2 אין צורך לפתוח את Claude Code שוב. Clicky משתמש בו ברקע.

---

## צעד 1: הורדה והתקנה של Clicky

### הורדה

> **מתקין ה-Windows עדיין לא נמצא בעמוד הזה.** הוא עובר לכאן. כדאי לבדוק שוב בקרוב, או לפתוח issue ב-repository ולכתוב שאתם מחכים לו.

### התקנה

1. לוחצים פעמיים על מתקין Clicky (קובץ `.exe`). לא צריך סיסמת מנהל.
2. אם Windows מציג **"Windows protected your PC"** (Clicky עוד לא חתום דיגיטלית), לוחצים **More info ← Run anyway**. זה צפוי.
3. מסיימים את ההתקנה. Clicky נפתח ומופיע ב-**system tray**, האייקון הקטן של הסמן ליד השעון. לא רואים? לוחצים על החץ **^** ליד השעון.

> אם Windows מסרב להריץ בכלל ("blocked by an Application Control policy"), זה אומר ש-**Smart App Control** דלוק. Clicky לא יכול לרוץ איתו עד שהוא ייחתם דיגיטלית.

## צעד 2: התקנת Claude Code והתחברות (פעם אחת)

### 2א. פותחים PowerShell

פותחים את תפריט התחלה, כותבים **PowerShell**, פותחים.

### 2ב. מתקינים את Claude Code

מדביקים את השורה הזו ולוחצים Enter. את הפקודות כותבים כמו שהן, באנגלית.

</div>

```powershell
irm https://claude.ai/install.ps1 | iex
```

<div dir="rtl">

ההתקנה לא מראה התקדמות בזמן ההורדה. מחכים עד שחוזרת השורה לכתיבה. ייתכן שיבקש קודם להתקין **Git for Windows**: מתקינים ומריצים שוב את השורה.

זו הפקודה מ[דף ההתקנה הרשמי של Anthropic](https://code.claude.com/docs/en/setup).

### 2ג. בודקים שההתקנה הצליחה

**סוגרים את חלון ה-PowerShell ופותחים חדש**, ואז כותבים:

</div>

```powershell
claude --version
```

<div dir="rtl">

✅ **מה אמור להופיע:** מספר גרסה, למשל `2.1.211 (Claude Code)`.

### 2ד. מתחברים עם חשבון Claude

ב-PowerShell כותבים:

</div>

```powershell
claude
```

<div dir="rtl">

ולוחצים Enter.

1. **הדפדפן נפתח.** מתחברים עם **אותו חשבון שבו אתם משתמשים ב-claude.ai** (זה שיש לו מנוי) ומאשרים גישה.
2. אם Claude Code שואל איך להתחבר, בוחרים **Claude account / subscription (חשבון Claude / מנוי)**, **לא** את אפשרות ה-Console / API.
3. אם הוא שואל כמה שאלות בפעם הראשונה (כמו ערכת צבעים), התשובות ברירת המחדל מתאימות.
4. ב-PowerShell תראו את Claude Code מחכה להודעה. **אתם מחוברים.**
5. כותבים `/exit` ולוחצים Enter כדי לסגור. לא תצטרכו לפתוח אותו שוב.

## צעד 3: לוודא ש-Clicky משתמש במנוי Claude

1. **סוגרים את Clicky ופותחים אותו מחדש**, כדי שיזהה את Claude Code: קליק ימני על האייקון ב-tray ← **Quit Clicky**, ואז פותחים את Clicky מתפריט התחלה.
2. לוחצים על האייקון של Clicky. מוודאים שיש **✓** ליד **Use my Claude subscription (no API key)**. אם אין, לוחצים עליו.
3. באותו תפריט פותחים **Vision model**. ליד **Cloud – Claude** אמור להיות ✓.

---

## צעד 4: ההפעלה הראשונה (סבלנות, פעם אחת)

בפעם הראשונה Clicky מוריד **לבד** את מה שהוא צריך: מודלי הדיבור וכמה חבילות עזר. בסך הכול זה יכול להגיע לכמה ג'יגה. ההתקדמות מופיעה בפאנל קטן **למעלה מימין** במסך.

- משאירים את Clicky פתוח ונשארים על Wi-Fi. לוקח כמה דקות.
- עד שזה נגמר, התשובות הראשונות עלולות להיות איטיות.
- זה קורה רק פעם אחת. הפעלות הבאות מהירות (תנו לו כדקה אחרי שפותחים).

## צעד 5: מנסים

1. מחזיקים **Ctrl ימני**.
2. אומרים: **"מה יש לי על המסך?"**
3. עוזבים.

✅ **מה אמור לקרות:** רואים את האנימציה הקטנה ו-Clicky עונה בקול תוך כמה שניות.

שום דבר לא קרה? עוברים ל[משהו לא עובד?](#משהו-לא-עובד) למטה.

## איך משתמשים ב-Clicky

**מחזיקים את המקש, מדברים, עוזבים.**

| | Windows |
|---|---|
| **תעשה בשבילי.** Clicky לוחץ ומקליד בזמן שאתם מסתכלים. | מחזיקים **Ctrl ימני** |
| **תדריך אותי.** Clicky מצביע, אתם לוחצים. | מחזיקים **Alt ימני** |

קליק ימני על האייקון ב-tray מראה איזה מקש עושה מה ומאפשר לשנות הגדרות.

**טוב לדעת**

- **להקיף משהו בעכבר** בזמן שמחזיקים את המקש, כדי להראות בדיוק למה התכוונתם.
- **לחיצה קצרה** על המקש עוצרת את Clicky. **Esc** עוצר משימה ומנקה את הציורים.
- אומרים **"תקריא לי את העמוד"** והוא מקריא את העמוד בקול. לוחצים על המקש כדי לעצור.
- Clicky **שואל לפני** כל דבר שאי אפשר לבטל (שליחה, קנייה, מחיקה) ו**אף פעם לא מקליד סיסמאות**.
- **שפת התשובות:** בתפריט ה-tray בוחרים **Language**, או פותחים **Settings…** ← "Answer in".

כל שאלה נספרת במגבלות השימוש של מנוי Claude שלכם, כמו שימוש רגיל ב-Claude. כברירת מחדל Clicky משתמש במודל הקטן והמהיר של Claude, **Haiku**.

## משהו לא עובד?

| מה רואים | מה עושים |
|---|---|
| **"Claude Code was not found"** | עושים שוב את [צעד 2](#צעד-2-התקנת-claude-code-והתחברות-פעם-אחת). בודקים ש-`claude --version` עובד בחלון PowerShell **חדש**. ואז סוגרים ופותחים מחדש את Clicky. |
| **"Claude Code needs you to sign in again"** | ב-PowerShell כותבים `claude`, ואז `/login`, מתחברים, ואז `/exit`. |
| **כלום לא קורה כשמחזיקים את המקש** | קליק ימני על אייקון ה-tray ← **Settings…** ובודקים את המקשים. ואז סוגרים ופותחים מחדש את Clicky. |
| **"I didn't hear anything" / Clicky לא שומע אותי** | בודקים את המיקרופון: Settings ← System ← Sound ← Input. מדברים ורואים שהפס זז. |
| **אני לא שומע את Clicky** | בודקים את התקן הפלט ואת עוצמת הקול. אם אתם עם אוזניות Bluetooth, מנסים את הרמקולים של המחשב. |
| **איטי בדקה הראשונה אחרי הפתיחה** | רגיל: Clicky טוען את המודלים שלו. נותנים לו דקה. |
| **התשובה בשפה לא נכונה** | תפריט ה-tray ← **Language**, או **Settings…** ← "Answer in". |
| **כל דבר אחר** | קליק ימני על אייקון ה-tray ← **Diagnostics…**. הוא מפרט מה לא תקין ואיך לתקן. |

אם יש שגיאה ורוצים לקרוא מה Claude Code עצמו אומר, מריצים ב-PowerShell `claude doctor`.

## פרטיות

- **הקול שלכם** הופך לטקסט **על המחשב שלכם**. ההקלטה לא יוצאת ממנו.
- כששואלים משהו, **צילום של המסך והשאלה** נשלחים ל-**Claude** (Anthropic), דרך ההתחברות שלכם ב-Claude Code. **שום דבר לא נשלח כשלא מחזיקים את המקש.**
- Clicky לא שומר צילומי מסך. היסטוריית הטקסט נשארת במחשב שלכם.
- חלות מדיניות הנתונים של Claude עבור התוכנית שלכם על מה שנשלח אליו.
