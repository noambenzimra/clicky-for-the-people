# התקנת Clicky עם מנוי ChatGPT (‏Codex)

[→ חזרה להתחלה](../../README.md) · [English](../en/mac-codex.md) · [אני עם Claude](mac-claude.md)

> **העמוד הזה למק.** אפשרות ה-Codex נבדקה רק בגרסת המק של Clicky. יש לכם Windows? [עוברים לעמוד של Windows](windows-claude.md) (הוא עובד עם Claude).

**הזמן שלך:** בערך 10 דקות, ועוד כמה דקות של הורדות אוטומטיות בפעם הראשונה שפותחים את Clicky.
**עלות:** שום דבר מעבר לתוכנית ChatGPT שאתם כבר משלמים עליה. בלי מפתח API.

---

## לפני שמתחילים

| מה צריך | פרטים |
|---|---|
| **מק** | שבב Apple (‏M1, M2, M3 או M4) ו-macOS 14 ומעלה. 16GB זיכרון זה נוח. |
| **תוכנית ChatGPT שכוללת Codex** | Plus, Pro, Team, Edu או Enterprise. מה כלול בתוכנית שלכם אפשר לראות ב[דף ההתחברות של OpenAI](https://learn.chatgpt.com/docs/auth). |
| **כ-5GB פנויים בדיסק** | Clicky מוריד את מודלי הדיבור והקול בפעם הראשונה. |
| **אינטרנט** | להתקנה ולהפעלה הראשונה. |
| **מיקרופון** | המובנה מספיק. |

## איך זה עובד (30 שניות)

Clicky עונה לכם בעזרת ChatGPT. הוא מדבר איתו דרך **Codex**, אפליקציית שורת הפקודה הרשמית של OpenAI, שמחוברת לחשבון ה-ChatGPT שלכם. לכן יש ארבעה צעדים קטנים:

1. **להתקין את Clicky.**
2. **להתקין את Codex ולהתחבר** (פעם אחת).
3. **להגיד ל-Clicky להשתמש ב-ChatGPT (Codex).**
4. **לנסות.**

אחרי צעד 2 אין צורך לפתוח את Codex בעצמכם. Clicky משתמש בו ברקע, ורק כדי **לענות**: הוא מריץ את Codex במצב קריאה בלבד, בתיקייה זמנית ריקה, כך שאין לו גישה לקבצים שלכם, ומבקש ממנו לא לשמור סשן בדיסק.

> **צפו לקצת יותר איטי מ-Claude.** Clicky נבנה וכוונן קודם כול עם Claude. עם Codex תשובה בדרך כלל מתחילה כמה שניות מאוחר יותר (בערך 3 עד 6 שניות), והחץ שמצביע על דברים עשוי להיות פחות מדויק. אם יש לכם את שני המנויים, אפשר לעבור ביניהם בכל רגע (ראו [מעבר בין Claude ל-ChatGPT](#מעבר-בין-claude-ל-chatgpt)).

## צעד 1: הורדה והתקנה של Clicky

1. לוחצים על **[הורדת Clicky-macOS.dmg](https://github.com/noambenzimra/clicky-for-the-people/releases/latest/download/Clicky-macOS.dmg)**. הקובץ מתחיל לרדת מיד והעמוד הזה נשאר פתוח. זה קובץ אחד, בערך 32MB.
2. לוחצים עליו פעמיים. נפתח חלון עם **Clicky** וקיצור ל-**Applications**. גוררים את **Clicky** אל **Applications**.
3. פותחים את **Clicky**: לוחצים `⌘ Space`, כותבים **Clicky**, Enter.
4. בפעם הראשונה macOS אומר שאי אפשר לפתוח, כי Clicky עוד לא חתום אצל Apple. זה צפוי. עושים את זה פעם אחת:
   **System Settings (הגדרות מערכת) ← Privacy & Security (פרטיות ואבטחה)** ← גוללים למטה ל-**Security** ← לוחצים **Open Anyway (פתח בכל זאת)** ליד Clicky ← מאשרים עם סיסמה או Touch ID.
5. מאשרים את שלושת הדברים ש-Clicky מבקש:

   | הרשאה | בשביל מה |
   |---|---|
   | **Microphone (מיקרופון)** | לשמוע אתכם כשאתם מחזיקים את המקש. |
   | **Screen Recording (הקלטת מסך)** (ב-macOS חדש יותר: *Screen & System Audio Recording*) | לראות את המסך כשאתם שואלים שאלה. |
   | **Accessibility (נגישות)** | להצביע על דברים, ללחוץ בשבילכם ולקרוא טקסט מעמוד. |

   ייתכן ש-macOS יבקש **לסגור ולפתוח מחדש** את Clicky אחרי שמפעילים הקלטת מסך או נגישות. עושים את זה. לא בטוחים מה עוד חסר? לוחצים על האייקון של Clicky בשורת התפריטים ← **Setup & permissions…**.

✅ **מה אמור לקרות:** אין חלון ואין אייקון ב-Dock. Clicky חי כ**אייקון קטן של סמן עם קרניים בשורת התפריטים** בראש המסך.

## צעד 2: התקנת Codex והתחברות (פעם אחת)

### 2א. פותחים Terminal

לוחצים `⌘ Space`, כותבים **Terminal**, Enter.

### 2ב. מתקינים את Codex

מדביקים **את השורה הזו** ולוחצים Enter. את הפקודות כותבים כמו שהן, באנגלית.

</div>

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

<div dir="rtl">

זה המתקין של OpenAI עצמה, מ[דף ה-Codex CLI](https://learn.chatgpt.com/docs/codex/cli). הוא שם את הפקודה `codex` ב-`~/.local/bin` (שם Clicky מחפש אותה) ואם צריך מוסיף את התיקייה הזו ל-`~/.zprofile`. אם הוא שואל שאלה, לוחצים Enter לברירת המחדל.

אם אתם כבר משתמשים ב-Homebrew:

</div>

```bash
brew install --cask codex
```

<div dir="rtl">

אם כבר מותקן אצלכם Node.js:

</div>

```bash
npm install -g @openai/codex
```

</details>

### 2ג. בודקים שההתקנה הצליחה

**סוגרים את חלון ה-Terminal ופותחים חדש**, ואז כותבים:

</div>

```bash
codex --version
```

<div dir="rtl">

✅ **מה אמור להופיע:** מספר גרסה, למשל `codex-cli 0.172.0`.

⚠️ **אם כתוב `command not found`:** מריצים את זה פעם אחת, סוגרים את החלון, פותחים חדש ומנסים שוב:

</div>

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
```

<div dir="rtl">

### 2ד. מתחברים עם חשבון ChatGPT

</div>

```bash
codex login
```

<div dir="rtl">

1. **הדפדפן נפתח.** מתחברים עם **חשבון ה-ChatGPT שיש בו את התוכנית שלכם** ומאשרים גישה.
2. בחזרה ב-Terminal תראו **`Successfully logged in`**.

### 2ה. בודקים שאתם מחוברים

</div>

```bash
codex login status
```

<div dir="rtl">

✅ **מה אמור להופיע:** ‏`Logged in using ChatGPT`.

> משתמשים בהתחברות של **ChatGPT**, **לא** במפתח API. התחברות עם מפתח API מחויבת לפי שימוש, בנפרד מהתוכנית שלכם.

## צעד 3: להגיד ל-Clicky להשתמש ב-ChatGPT (‏Codex)

Clicky מתחיל כשהוא מכוון ל-Claude, ולכן הצעד הזה **חובה**.

1. לוחצים על **האייקון של Clicky** בשורת התפריטים.
2. פותחים **Vision model**.
3. בוחרים **ChatGPT subscription (Codex)**. יופיע לידו **✓**.

⚠️ **אם ליד השורה כתוב `(install Codex CLI)`:** Clicky לא מוצא את Codex. חוזרים לצעד 2ג, מוודאים ש-`codex --version` עובד בחלון Terminal חדש, ואז סוגרים ופותחים מחדש את Clicky.

אפשר להתעלם מהשורה *Use my Claude subscription* באותו תפריט.

## צעד 4: ההפעלה הראשונה (סבלנות, פעם אחת)

בפעם הראשונה Clicky מוריד **לבד** את מה שהוא צריך, בערך **4GB** בסך הכול: מודלי הדיבור, הקול העברי וכמה חבילות עזר. ההתקדמות מופיעה בפאנל קטן **למעלה מימין** ("Getting ready…", "Downloading the Hebrew voice").

- משאירים את Clicky פתוח ונשארים על Wi-Fi. לוקח כמה דקות.
- עד שזה נגמר, תשובות בעברית עשויות להישמע בקול הבסיסי של המק, והתשובות הראשונות עלולות להיות איטיות.
- זה קורה רק פעם אחת. הפעלות הבאות מהירות (תנו לו כדקה אחרי שפותחים).

## איך משתמשים ב-Clicky

**מחזיקים את המקש, מדברים, עוזבים.**

| | מק |
|---|---|
| **תעשה בשבילי.** Clicky לוחץ ומקליד בזמן שאתם מסתכלים. | מחזיקים **fn + Control** |
| **תדריך אותי.** Clicky מצביע, אתם לוחצים. | מחזיקים **⌘ ימני** |

בראש התפריט של Clicky תמיד כתוב איזה מקש עושה מה. כדי להחליף ביניהם: תפריט ← השורה שמתחילה במקש הראשי ואומרת **does** ← **Do it for me** או **Guide me**. מקשים אחרים: תפריט ← **Settings…**.

**טוב לדעת**

- **להקיף משהו בעכבר** בזמן שמחזיקים את המקש, כדי להראות בדיוק למה התכוונתם.
- **לחיצה קצרה** על המקש עוצרת את Clicky. **Esc** עוצר משימה ומנקה את הציורים.
- אומרים **"תקריא לי את העמוד"** והוא מקריא את העמוד בקול. לוחצים על המקש כדי לעצור.
- אומרים **"תסביר לי איך … עובד"** והוא מצייר הסבר חזותי ליד המסך.
- Clicky **שואל לפני** כל דבר שאי אפשר לבטל (שליחה, קנייה, מחיקה) ו**אף פעם לא מקליד סיסמאות**.
- **הקול העברי:** תפריט ← **Hebrew voice** ← קול נשי או גברי, בכל רגע. מהירות: **Settings…** ← Voice.
- **שפת התשובות:** תפריט ← **Language**, או **Settings…** ← "Answer in".

כל שאלה נספרת במגבלות השימוש של Codex בתוכנית ה-ChatGPT שלכם.

### מעבר בין Claude ל-ChatGPT

יש לכם את שניהם? תפריט ← **Vision model** ← בוחרים **Cloud – Claude** או **ChatGPT subscription (Codex)**. השינוי חל מהשאלה הבאה. (כדי להשתמש ב-Claude צריך גם Claude Code, ראו [המדריך ל-Claude](mac-claude.md).)

## משהו לא עובד?

| מה רואים | מה עושים |
|---|---|
| **"Codex CLI is not installed"** | עושים שוב את [צעד 2](#צעד-2-התקנת-codex-והתחברות-פעם-אחת). בודקים ש-`codex --version` עובד בחלון Terminal **חדש**. ואז סוגרים ופותחים מחדש את Clicky. |
| **"Codex needs you to sign in"** | ב-Terminal מריצים `codex login`, מתחברים עם חשבון ה-ChatGPT, ואז בודקים `codex login status`. |
| **ליד השורה כתוב `(install Codex CLI)`** | Clicky לא מוצא את Codex. ראו צעד 3. |
| **`command not found: codex`** | סוגרים את ה-Terminal ופותחים חלון חדש. עדיין לא נמצא: מריצים את שורת ה-`export PATH=…` מצעד 2ג. |
| **שגיאה על שימוש או מגבלה** | ניצלתם את מכסת ה-Codex של התוכנית שלכם לעכשיו. מחכים שתתאפס, או עוברים ל-Claude (ראו למעלה). |
| **כלום לא קורה כשמחזיקים את המקשים** | תפריט ← **Setup & permissions…** ומפעילים כל מה שכבוי (במיוחד Accessibility ו-Screen Recording). ואז סוגרים ופותחים מחדש את Clicky. |
| **"I didn't hear anything" / Clicky לא שומע אותי** | בודקים את המיקרופון: System Settings ← Sound ← Input. מדברים ורואים שהפס זז. |
| **אני לא שומע את Clicky** | בודקים את התקן הפלט ואת עוצמת הקול. אם אתם עם אוזניות Bluetooth, מנסים את הרמקולים של המק. |
| **איטי** | ממש אחרי הפתיחה נותנים לו דקה (הוא טוען). Codex גם איטי ב-3 עד 6 שניות מ-Claude, זה חלק מהעניין. |
| **התשובה בשפה לא נכונה** | תפריט ← **Language**, או **Settings…** ← "Answer in". |
| **כל דבר אחר** | לוחצים על האייקון של Clicky ← **Diagnostics…**. הוא מפרט מה לא תקין ואיך לתקן. |

## פרטיות

- **הקול שלכם** הופך לטקסט **על המק שלכם**. ההקלטה לא יוצאת ממנו.
- כששואלים משהו, **צילום של המסך והשאלה** נשלחים ל-**OpenAI**, דרך ההתחברות שלכם ב-Codex. **שום דבר לא נשלח כשלא מחזיקים את המקש.**
- Clicky מריץ את Codex ב**מצב קריאה בלבד**, ב**תיקייה זמנית ריקה**, ומבקש ממנו **לא לשמור סשן** במחשב. דרך Clicky, ל-Codex אין גישה לקרוא או לשנות את הקבצים שלכם.
- Clicky לא שומר צילומי מסך. היסטוריית הטקסט נשארת במק שלכם (תפריט ← **History…** כדי לראות או למחוק).
- חלות מדיניות הנתונים של OpenAI עבור התוכנית שלכם על מה שנשלח אליה.
