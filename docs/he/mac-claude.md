# התקנת Clicky עם מנוי Claude

[→ חזרה להתחלה](../../README.md) · [English](../en/mac-claude.md) · [אני עם ChatGPT / Codex](mac-codex.md)

> **העמוד הזה למק.** יש לכם Windows? [עוברים לעמוד של Windows](windows-claude.md).

**הזמן שלך:** בערך 10 דקות, ועוד כמה דקות של הורדות אוטומטיות בפעם הראשונה שפותחים את Clicky.
**עלות:** שום דבר מעבר למנוי Claude שאתם כבר משלמים עליו. בלי מפתח API.

---

## לפני שמתחילים

| מה צריך | פרטים |
|---|---|
| **מק** | שבב Apple (‏M1, M2, M3 או M4) ו-macOS 14 ומעלה. 16GB זיכרון זה נוח. |
| **מנוי Claude** | **Pro או Max** (גם Ultra, Team ו-Enterprise עובדים). התוכנית החינמית של claude.ai **לא** כוללת את Claude Code, ו-Clicky צריך אותו. |
| **כ-5GB פנויים בדיסק** | Clicky מוריד את מודלי הדיבור והקול בפעם הראשונה. |
| **אינטרנט** | להתקנה ולהפעלה הראשונה. |
| **מיקרופון** | המובנה מספיק. |

## איך זה עובד (30 שניות)

Clicky עונה לכם בעזרת Claude. הוא מדבר עם Claude דרך **Claude Code**, האפליקציה הרשמית של Anthropic, שמחוברת למנוי שלכם. לכן יש ארבעה צעדים קטנים:

1. **להתקין את Clicky.**
2. **להתקין את Claude Code ולהתחבר** (פעם אחת).
3. **להגיד ל-Clicky להשתמש במנוי Claude שלכם.**
4. **לנסות.**

אחרי צעד 2 אין צורך לפתוח את Claude Code שוב. Clicky משתמש בו ברקע.

---

## צעד 1: הורדה והתקנה של Clicky

### הורדה

לוחצים על **[הורדת Clicky-macOS.dmg](https://github.com/noambenzimra/clicky-for-the-people/releases/latest/download/Clicky-macOS.dmg)**. הקובץ מתחיל לרדת מיד והעמוד הזה נשאר פתוח. זה קובץ אחד, בערך 32MB.

### התקנה

1. לוחצים פעמיים על `Clicky-macOS.dmg`. נפתח חלון עם **Clicky** וקיצור ל-**Applications**. גוררים את **Clicky** אל **Applications**.
2. פותחים את **Clicky**: לוחצים `⌘ Space`, כותבים **Clicky**, Enter.
3. בפעם הראשונה macOS אומר שאי אפשר לפתוח, כי Clicky עוד לא חתום אצל Apple. זה צפוי. עושים את זה פעם אחת:
   **System Settings (הגדרות מערכת) ← Privacy & Security (פרטיות ואבטחה)** ← גוללים למטה ל-**Security** ← לוחצים **Open Anyway (פתח בכל זאת)** ליד Clicky ← מאשרים עם סיסמה או Touch ID.
4. מאשרים את שלושת הדברים ש-Clicky מבקש:

   | הרשאה | בשביל מה |
   |---|---|
   | **Microphone (מיקרופון)** | לשמוע אתכם כשאתם מחזיקים את המקש. |
   | **Screen Recording (הקלטת מסך)** (ב-macOS חדש יותר: *Screen & System Audio Recording*) | לראות את המסך כשאתם שואלים שאלה. |
   | **Accessibility (נגישות)** | להצביע על דברים, ללחוץ בשבילכם ולקרוא טקסט מעמוד. |

   ייתכן ש-macOS יבקש **לסגור ולפתוח מחדש** את Clicky אחרי שמפעילים הקלטת מסך או נגישות. עושים את זה. לא בטוחים מה עוד חסר? לוחצים על האייקון של Clicky בשורת התפריטים ← **Setup & permissions…**.

✅ **מה אמור לקרות:** אין חלון ואין אייקון ב-Dock. Clicky חי כ**אייקון קטן של סמן עם קרניים בשורת התפריטים** בראש המסך.

## צעד 2: התקנת Claude Code והתחברות (פעם אחת)

### 2א. פותחים טרמינל

לוחצים `⌘ Space`, כותבים **Terminal**, Enter.

### 2ב. מתקינים את Claude Code

מדביקים **שורה אחת** ולוחצים Enter. את הפקודות כותבים כמו שהן, באנגלית.

</div>

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

<div dir="rtl">

ההתקנה לא מראה התקדמות בזמן ההורדה. מחכים עד שחוזרת השורה לכתיבה.

אלה הפקודות מ[דף ההתקנה הרשמי של Anthropic](https://code.claude.com/docs/en/setup).

### 2ג. בודקים שההתקנה הצליחה

**סוגרים את חלון הטרמינל ופותחים חדש**, ואז כותבים:

</div>

```bash
claude --version
```

<div dir="rtl">

✅ **מה אמור להופיע:** מספר גרסה, למשל `2.1.211 (Claude Code)`.

⚠️ **אם כתוב `command not found`:** מריצים את זה פעם אחת, סוגרים את החלון, פותחים חדש ומנסים שוב:

</div>

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
```

<div dir="rtl">

### 2ד. מתחברים עם חשבון Claude

בטרמינל כותבים:

</div>

```bash
claude
```

<div dir="rtl">

ולוחצים Enter.

1. **הדפדפן נפתח.** מתחברים עם **אותו חשבון שבו אתם משתמשים ב-claude.ai** (זה שיש לו מנוי) ומאשרים גישה.
2. אם Claude Code שואל איך להתחבר, בוחרים **Claude account / subscription (חשבון Claude / מנוי)**, **לא** את אפשרות ה-Console / API.
3. אם הוא שואל כמה שאלות בפעם הראשונה (כמו ערכת צבעים), התשובות ברירת המחדל מתאימות.
4. בטרמינל תראו את Claude Code מחכה להודעה. **אתם מחוברים.**
5. כותבים `/exit` ולוחצים Enter כדי לסגור. לא תצטרכו לפתוח אותו שוב.

## צעד 3: להגיד ל-Clicky להשתמש במנוי Claude

1. **סוגרים את Clicky** (אייקון בשורת התפריטים ← **Quit Clicky**) **ופותחים אותו מחדש** מ-Applications, כדי שיזהה את Claude Code.
2. לוחצים על האייקון של Clicky. מוודאים שיש **✓** ליד **Use my Claude subscription (no API key)**. אם אין, לוחצים עליו.
3. באותו תפריט פותחים **Vision model**. ליד **Cloud – Claude** אמור להיות ✓.

---

## צעד 4: ההפעלה הראשונה (סבלנות, פעם אחת)

בפעם הראשונה Clicky מוריד **לבד** את מה שהוא צריך, בערך **4GB** בסך הכול: מודלי הדיבור, הקול העברי וכמה חבילות עזר. ההתקדמות מופיעה בפאנל קטן **למעלה מימין** ("Getting ready…", "Downloading the Hebrew voice").

- משאירים את Clicky פתוח ונשארים על Wi-Fi. לוקח כמה דקות.
- עד שזה נגמר, תשובות בעברית עשויות להישמע בקול הבסיסי של המק, והתשובות הראשונות עלולות להיות איטיות.
- זה קורה רק פעם אחת. הפעלות הבאות מהירות (תנו לו כדקה אחרי שפותחים).

## צעד 5: מנסים

1. מחזיקים **fn + Control**.
2. אומרים: **"מה יש לי על המסך?"**
3. עוזבים.

✅ **מה אמור לקרות:** רואים את האנימציה הקטנה ו-Clicky עונה בקול תוך כמה שניות.

שום דבר לא קרה? עוברים ל[משהו לא עובד?](#משהו-לא-עובד) למטה.

## איך משתמשים ב-Clicky

**מחזיקים את המקש, מדברים, עוזבים.**

| | מק |
|---|---|
| **תעשה בשבילי.** Clicky לוחץ ומקליד בזמן שאתם מסתכלים. | מחזיקים **fn + Control** |
| **תדריך אותי.** Clicky מצביע, אתם לוחצים. | מחזיקים **⌘ ימני** |

בראש התפריט של Clicky תמיד כתוב איזה מקש עושה מה. כדי להחליף ביניהם: תפריט ← השורה שמתחילה במקש הראשי ואומרת **does** ← **Do it for me** או **Guide me**. מקשים אחרים: תפריט ← **Settings…**.

**טוב לדעת**

- **להקיף משהו בעכבר** בזמן שמחזיקים את המקש, כדי להראות בדיוק למה התכוונתם.
- **לחיצה קצרה** על המקש עוצרת את Clicky. **Esc** עוצר משימה ומנקה את הציורים.
- אומרים **"תקריא לי את העמוד"** והוא מקריא את העמוד בקול. לוחצים על המקש כדי לעצור.
- אומרים **"תסביר לי איך … עובד"** והוא מצייר הסבר חזותי ליד המסך.
- Clicky **שואל לפני** כל דבר שאי אפשר לבטל (שליחה, קנייה, מחיקה) ו**אף פעם לא מקליד סיסמאות**.
- **הקול העברי:** תפריט ← **Hebrew voice** ← קול נשי או גברי, בכל רגע. מהירות: **Settings…** ← Voice.
- **שפת התשובות:** תפריט ← **Language**, או **Settings…** ← "Answer in".

כל שאלה נספרת במגבלות השימוש של מנוי Claude שלכם, כמו שימוש רגיל ב-Claude. כברירת מחדל Clicky משתמש במודל הקטן והמהיר של Claude, **Haiku**.

## משהו לא עובד?

| מה רואים | מה עושים |
|---|---|
| **"Claude Code was not found"** | עושים שוב את [צעד 2](#צעד-2-התקנת-claude-code-והתחברות-פעם-אחת). בודקים ש-`claude --version` עובד בחלון טרמינל **חדש**. ואז סוגרים ופותחים מחדש את Clicky. |
| **"Claude Code needs you to sign in again"** | בטרמינל כותבים `claude`, ואז `/login`, מתחברים, ואז `/exit`. |
| **`command not found: claude`** | סוגרים את הטרמינל ופותחים חדש. עדיין לא נמצא: מריצים את שורת ה-`export PATH=…` מצעד 2ג. |
| **כלום לא קורה כשמחזיקים את המקשים** | תפריט ← **Setup & permissions…** ומפעילים כל מה שכבוי (במיוחד Accessibility ו-Screen Recording). ואז סוגרים ופותחים מחדש את Clicky. |
| **"I didn't hear anything" / Clicky לא שומע אותי** | בודקים את המיקרופון: System Settings ← Sound ← Input. מדברים ורואים שהפס זז. |
| **אני לא שומע את Clicky** | בודקים את התקן הפלט ואת עוצמת הקול. אם אתם עם אוזניות Bluetooth, מנסים את הרמקולים של המחשב. |
| **איטי בדקה הראשונה אחרי הפתיחה** | רגיל: Clicky טוען את המודלים שלו. נותנים לו דקה. |
| **התשובה בשפה לא נכונה** | תפריט ← **Language**, או **Settings…** ← "Answer in". |
| **כל דבר אחר** | לוחצים על האייקון של Clicky ← **Diagnostics…**. הוא מפרט מה לא תקין ואיך לתקן. |

אם יש שגיאה ורוצים לקרוא מה Claude Code עצמו אומר, מריצים בטרמינל `claude doctor`.

## פרטיות

- **הקול שלכם** הופך לטקסט **על המחשב שלכם**. ההקלטה לא יוצאת ממנו.
- כששואלים משהו, **צילום של המסך והשאלה** נשלחים ל-**Claude** (Anthropic), דרך ההתחברות שלכם ב-Claude Code. **שום דבר לא נשלח כשלא מחזיקים את המקש.**
- Clicky לא שומר צילומי מסך. היסטוריית הטקסט נשארת במחשב שלכם (תפריט ← **History…** כדי לראות או למחוק).
- חלות מדיניות הנתונים של Claude עבור התוכנית שלכם על מה שנשלח אליו.
